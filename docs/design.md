# 划词与截图翻译器：功能设计

用户要求：独立桌面软件，便于继续修改，支持 Windows 与 Linux；仅两个核心入口：截图翻译、实时划词翻译。截图和总开关各有可配置的全局快捷键。先完成功能，界面不进行视觉样式设计。

## 行为

- 划词指鼠标拖选文本，松开后等待 450ms 稳定再翻译，不是鼠标悬停自动推测句子。重复选区不重复请求，拖选过程中不发送半句。
- 截图快捷键默认 Ctrl+Alt+S，总开关默认 Ctrl+Alt+T，设置可修改。关闭后停止新请求，隐藏窗口，丢弃在途结果。总开关仍能恢复翻译。
- 日常模式使用用户自己的百度通用翻译 App ID 和密钥。
- 论文模式先获得百度初译，再使用用户自己的兼容 Chat Completions 协议的 AI 接口复核原文和初译。只展示最终精校译文，必要时简短提示歧义；复核失败不展示初译。术语判断在翻译内部完成。可设置学科、源语言和目标语言。
- 论文模式不保证绝对正确；不把模型自报置信度当事实。无上下文时标明歧义，保留原文供核对。OCR 结果可编辑后重新翻译。
- 截图 OCR 在本地通过 Tesseract 完成，英语默认 eng，支持安装后的其他语言包。识别不出文字时不调用 API。

## 架构

Python 3.10+ 与 PySide6；界面、翻译、配置、请求状态、OCR、系统适配分别独立。网络和 OCR 在线程池中执行，最多一个任务正在执行、一个最新任务等待，避免实时划词淹没 API。模式、配置、开关发生变化时旧结果失效。

Windows：原生全局快捷键，UI Automation 读取文本选区，Qt 区域截图。Linux X11：原生 X11 快捷键和 PRIMARY 选区，Qt 区域截图。Ubuntu GNOME Wayland：小型 GNOME 辅助组件读取 PRIMARY 选区及绑定快捷键，通过用户专属本地 socket 交给独立 Qt 软件；截图通过桌面 Screenshot portal。辅助组件没有翻译界面和 API 密钥。其他 Wayland 桌面提供手动粘贴入口，不声称自动划词通用兼容。

凭据优先保存在系统密钥库，不在日志中记录；没有可用安全密钥库时仅本次运行保存凭据，并明确提示。设置文件只包含非密钥项。选区仅在功能启用时发送翻译。历史缓存仅在内存，不写论文内容到磁盘。

## 验证与交付

测试覆盖真实 HTTP 协议边界、百度签名/错误码、论文复核结构与降级提示、超时、去抖、暂停与过期结果、配置/密钥、OCR、IPC 和截图取消。无用户真实凭据时使用本地 HTTP 测试服务；不虚报真实 API 验证。Windows 原生适配在 Windows 上实测后才能宣称完整兼容。

交付可修改源码、中文说明、Linux 启动/安装脚本、Windows 启动与打包脚本及测试。

## 0.2 Zotero 接入

面向用户 Zotero 9.0.1，通过官方 renderTextSelectionPopup 事件获得选区，450ms 去抖。插件在本地读取私有连接文件，通过仅绑定 127.0.0.1 的随机端口和每次启动令牌发送输入。暂停与设置修改轮换 generation，服务端和 UI 均丢弃旧消息。论文模式仅从当前选中页面提取围绕选区的有限上下文，最多 4000 字符，作为消歧资料；上下文提取不使用全文，失败时仅发送选区。插件不修改标注和数据库，不读取 API 密钥。阅读器内部 PDF.js 上下文接口为可选适配，需要真实 Zotero 联调。
