# 第一版验证记录

验证环境：Ubuntu 26.04、GNOME Shell 50.1、Wayland、x86_64；开发 Python 3.12、Qt Essentials 6.10.3。

## 已执行

- 62 项 Python 测试通过：配置与密钥隔离、百度签名与本地 HTTP 请求、论文复核解析与失败拦截、禁止带凭据请求跳转、暂停/过期结果/最新任务队列、OCR 错误、IPC、设置界面、截图取消、平台选区状态。
- GNOME JavaScript 选区状态测试通过：拖选、稳定延迟、重复选区、暂停恢复与首次读取。
- GNOME 组件语法检查、GSettings schema 严格编译、启动和安装脚本语法检查通过。
- 使用真实私有 D-Bus 会话验证 Qt 截图 portal 请求、响应与旧响应过滤；不是只调用模拟的 Qt 方法。
- Ubuntu 实际 Wayland 环境中，源码应用和打包应用启动并正常退出。
- 本地 Tesseract 5.5.0 对生成的英语截图实际识别出“Attention mechanism improves translation.”；便携包 OCR 二进制和英语模型已验证。
- 代码审查发现的凭据重定向、Windows UIA 阻塞、截图旧响应、自身窗口选区、Wayland 旧请求，以及 X11 快速暂停恢复问题已修复。

## 需要用户环境联调

- 未安装并启用用户的 GNOME 组件，因此真实 PDF 阅读器/浏览器中的实时划词、全局快捷键与结果定位尚需实机体验。已检查宿主 GNOME 提供组件所需接口。
- Windows 平台适配和构建脚本已实现，尚未在 Windows 真机运行或生成 Windows 可执行包。
- 没有实际百度/AI 账号密钥；协议测试使用本地 HTTP 服务。真实接口配额、模型兼容性与论文术语质量需配置后验证。
- X11 全局输入未在真实 X11 桌面运行。
- 应用不能读取未提供文本选区的阅读器；图片型 PDF 应使用截图。OCR 默认英语；中英截图请在设置中填 eng+chi_sim，便携包已附简体中文模型。

论文模式只展示最终译文与必要歧义，复核失败时不展示初译，不宣称自动译文绝对正确。请结合原文核对论文中的关键术语。

更新：复现并修复 GNOME 辅助组件短连接引发的 QLocalSocket abort 动态方法警告，新增真实 Unix 客户端回归测试，包含未发送完整命令的连接超时验证。

更新：新增默认开启的中英自动互译；日常请求与论文复核均使用检测后的方向。验证中文、英文、中英混合、扩展汉字、无语言文字、手动覆盖和设置界面。
